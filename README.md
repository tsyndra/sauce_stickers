# SauceStickers — печать круглых наклеек 50 мм

Windows-приложение для печати наклеек на соусы на термопринтере Xprinter XP-365B.

## Запуск из исходников

```bat
pip install -r requirements.txt
python main.py
```

## Сборка exe

```bat
build.bat
```

Исполняемый файл: `dist\SauceStickers.exe`

## Настройка принтера XP-365B

1. Установите драйвер Xprinter XP-365B с сайта производителя или Seagull Scientific.
2. В свойствах принтера выберите режим **Label** (этикетки), не Receipt.
3. Создайте пользовательский размер носителя **50 × 50 mm** (квадрат под круглые наклейки 50 мм).
4. Укажите зазор между этикетками (gap), если используете рулон с метками.
5. После первой пробной печати при необходимости подстройте смещение в настройках драйвера.

## Использование

1. Выберите принтер в выпадающем списке (последний выбор сохраняется).
2. Укажите количество наклеек.
3. Нажмите кнопку нужного соуса — печать начнётся сразу.

На наклейке печатаются: название, дата изготовления, «Годен до» (+24 часа), масса нетто, условия хранения и состав.

## Редактирование составов и масс

Данные хранятся в файле `sauces.py`:

- `composition` — текст после «Состав:»
- `weight_g` — масса нетто в граммах
- `label_title` — крупный заголовок на наклейке

После изменения `sauces.py` пересоберите exe командой `build.bat` или запускайте через `python main.py`.
