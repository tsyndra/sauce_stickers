# SauceStickers — печать круглых наклеек 40 мм

Windows-приложение для печати наклеек на соусы и десерты (Xprinter / Zebra и др. через драйвер Windows).

## Запуск из исходников

```bat
pip install -r requirements.txt
python main.py
```

## Сборка exe

```bat
build.bat
```

Исполняемый файл: `dist\SauceStickers.exe`  
Манифест обновлений: `dist\version.json`

Перед релизом поднимите номер в `version.py` → `APP_VERSION`.

## Автообновление

1. Создайте папку на сетевой шаре, например `\\fileserver\Share\SauceStickers`.
2. После `build.bat` скопируйте туда:
   - `SauceStickers.exe`
   - `version.json`
3. Укажите эту папку одним из способов:
   - в `version.py`: `DEFAULT_UPDATE_BASE = r"\\fileserver\Share\SauceStickers"` и пересоберите;
   - или файл `update_base.txt` рядом с exe на филиале (одна строка — путь/URL);
   - или в `%APPDATA%\SauceStickers\config.json` поле `"update_base"`.

При запуске приложение само проверяет `version.json`. Кнопка **Проверить обновления** — вручную.  
Если версия новее — скачает exe, заменит файл и перезапустится.

Также поддерживается HTTP(S)-каталог с теми же файлами.

## Настройка принтера

1. Установите драйвер принтера (Xprinter XP-365B, Zebra ZD410 и т.п.).
2. В свойствах принтера выберите режим **Label** (этикетки).
3. Один раз создайте/выберите размер носителя **40 × 40 mm** (в приложении — кнопка **Настройки…**).
4. Сглаживание/дизеринг лучше выключить («Нет»).
5. При печати приложение само подставляет **40×40 mm** в задание — менять размер каждый раз обычно не нужно.
6. После пробной печати при необходимости подстройте смещение в драйвере.

Сетевой принтер (в т.ч. общий с другого ПК): добавьте его в Windows — он появится в списке приложения.

## Использование

1. При первом запуске на ПК выберите **ИП филиала** (сохраняется в `%APPDATA%\SauceStickers`, не копируется вместе с exe).
2. Выберите принтер (последний выбор сохраняется).
3. Укажите количество наклеек.
4. Вкладка **Соусы** или **Десерты** — нажмите нужную позицию.

### Соусы

На наклейке: название, дата изготовления, «Годен до» (сутки минус 1 минута), масса нетто, условия хранения и состав.

Данные: `sauces.py`.

### Десерты (HATIMAKI)

На наклейке: бренд, название, **Разморожен** (время печати), **Годен до** (по сроку после дефростации), температура хранения, выбранный ИП филиала.

Данные и сроки: `desserts.py`.

После изменения данных пересоберите exe (`build.bat`) или запускайте `python main.py`.
